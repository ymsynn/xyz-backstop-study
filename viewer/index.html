Each line on these charts is a replay: a recorded day of one of trade.xyz's markets, run again in a rebuilt copy of Hyperliquid's engine under a chosen set of rules. Pick a test, change a part of the formulas, and add the combination to compare it with today's rules and with the proposal. The page computes nothing: a combination that was not replayed cannot be picked.
